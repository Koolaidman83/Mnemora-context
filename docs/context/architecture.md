# Mnemora context architecture

**Status:** proposed / bootstrap.

Mnemora aims to support a private local memory store, a reviewed export process, versioned public-safe snapshots, and local offline copies. A future authenticated API or MCP tool may provide scoped private retrieval. GitHub Pages is static hosting, not a live query API.

No credentials, private records, raw transcripts, health details, or personal profiles belong in this public repository.
