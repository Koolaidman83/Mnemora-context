# Mnemora Dynamic Corpus Discovery

## Architecture
Mnemora uses GitHub as its canonical public corpus.
Cloudflare MCP retrieves the public knowledge registry.
Netlify provides browser-based access.

## Expansion
New subjects and nested directories are supported.
Markdown, TXT and JSON documents are discovered recursively.

## Contribution interfaces
- Termux corpus publisher
- StackEdit through GitHub
- Obsidian through planned selective import
- Notion through planned API integration
- External AI-generated contributions

## Publication
Run mcorpus index, mcorpus validate and mcorpus publish.
Review all public material before approving publication.

## Privacy
Private memory remains isolated.
Public MCP access is read-only.
