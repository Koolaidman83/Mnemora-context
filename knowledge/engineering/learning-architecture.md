# Engineering learning architecture

## Learning progression
Requirements -> constraints -> physical principles -> models -> calculations -> simulation -> prototype -> measurement -> failure analysis -> revision.

## Initial subject map
Mechanics; circuits and electronics; signals and systems; control theory; communications; embedded computing; distributed systems; materials; reliability; safety engineering.

## Engineering record
Track assumptions, units, diagrams, source references, test conditions, observed results, uncertainty and design revisions. Distinguish hypotheses, plans and tested implementations.
