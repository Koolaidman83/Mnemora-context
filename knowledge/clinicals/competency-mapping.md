# Clinical and laboratory competency mapping

## Model
Competency -> prerequisites -> equipment -> preparation -> critical safety checks -> performance sequence -> reassessment -> documentation -> remediation.

## Practice modes
Skills validation checklists, medication and dosage calculations, simulated patient changes, structured feedback and reflective review.

## Evidence
Associate each competency with an authorized rubric, standard or cited source. Track student-specific scores and clinical records privately, never in the public knowledge corpus.
