# Mnemora: Project Bio

Mnemora is an experimental, local-first personal knowledge and AI memory project designed to preserve context across conversations, documents, devices, and AI tools.

The architecture brings together a private searchable memory index, conversation and document ingestion, small-device workers, and interfaces for retrieving relevant context. Early applications include clinical education study workflows, technical project continuity, and personal knowledge management.

The design emphasizes preserving original sources, traceable retrieval, portable deployment, and owner-controlled privacy.

**Status:** In development. Private indexing and retrieval components have been prototyped. Universal cross-AI integration and a live server-side callback endpoint have not been deployed.

**Public repository:** https://github.com/Koolaidman83/Mnemora-context

**Callback requests:** Open an issue in the public repository. Do not disclose personal contact details or confidential information in a public issue.
