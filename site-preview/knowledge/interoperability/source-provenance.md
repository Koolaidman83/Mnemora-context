# Source provenance and public/private boundary

Every knowledge record should identify domain, title, version, publication date, evidence status, source references and update history where available.

Public: original architecture descriptions, authorized educational explanations, generalized workflows, synthetic scenarios and published references.

Private: patient identifiers, student records, grades, institutional files, raw lecture recordings, copyrighted course packs, credentials, network details and local memory databases.

llms.txt is a discovery convention, not automatic model memory. MCP is a protocol for authorized clients to retrieve resources and call tools. Neither causes third-party models to retain knowledge permanently. Verify current clinical claims against authoritative sources before use.
