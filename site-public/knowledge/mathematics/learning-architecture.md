# Mathematics learning architecture

## Learning progression
Prerequisite graph -> conceptual explanation -> worked derivation -> unit and dimensional checks -> graded practice -> error classification -> spaced retrieval -> applied projects.

## Initial subject map
Arithmetic and units; algebra; functions and graphs; geometry; trigonometry; calculus; linear algebra; probability and statistics; differential equations; numerical methods.

## Evidence model
Preserve definitions, assumptions, derivation steps, examples, verification methods and source references. Prefer reproducible calculations over unsupported answers.
