# Mnemora collaboration MCP v0.1
Isolated bearer-authenticated prototype. Not OAuth-enabled; consumer MCP clients requiring OAuth cannot connect yet. No private memory access. Confirm D1 ID before deployment. Run schema.sql in the D1 console. Configure distinct random secrets CHATGPT_TOKEN, CLAUDE_TOKEN, OWNER_TOKEN (at least 32 characters) in Worker settings, never in Git. Deploy from collaboration directory using npx wrangler deploy. Without secrets all requests are denied. Task results should contain source references as text. All authenticated participants can read the shared ledger; do not store sensitive information. Test with synthetic tasks before use. No automated AI invocation.
